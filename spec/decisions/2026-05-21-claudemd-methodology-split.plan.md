**Goal:** Split the combined Forge `CLAUDE.md` into product-owned root agent files (CLAUDE.md / AGENTS.md / GEMINI.md, tracked) and Forge-owned methodology + CLI-surface doc (`.forge/CONTEXT.md`, gitignored, regenerated by `forge upgrade`).

**Architecture:** Bundled template `templates/CONTEXT.template.md` + generated CLI registry render into a single gitignored `.forge/CONTEXT.md`. Strict edit detection refuses to overwrite user edits; `--force` saves a `.bak`.

**Tech Stack:** TypeScript (ESM), Node.js native test runner (`node --test --import tsx`), `tsdown` bundler, `@inquirer/prompts` for interactive UI, `zod` for schema, `yaml` for settings.yaml parsing, `node:crypto` for SHA-256.

```markdown
## Principles

1. **Boil the Lake** — refuse weak inputs
2. **Iron Law of Investigation** — no fixes without RCA
3. **Confusion Protocol** — clarify, don't guess
4. **Test-or-die** — every PR ships with tests
5. **Compound Learning** — capture notable learnings
6. **Multi-model Second Opinion** — Codex on critical paths
7. **Plan Mode Mandatory** — no multi-file changes without /plan-task
8. **12-Factor Env Discipline** — never commit secrets

See [ETHOS.md](https://github.com/firatcand/forge/blob/main/ETHOS.md) for the full discussion of each principle.

## Source of truth

Forge projects are multi-artifact. Each artifact OWNS specific fields. When two artifacts seem to disagree, ask **"whose field is this?"** — not "which artifact ranks higher?"

| Artifact | Owns |
|----------|------|
| `spec/SPEC.md` | Architecture, constraints, non-functional requirements. Durable design-time truth. |
| `spec/PRD.md` | Product behavior, user-facing acceptance criteria. |
| `plans/phases.yaml` | Local execution snapshot (derived from tracker; do not hand-edit). |
| Tracker body (Linear / GitHub / Notion) | Live execution truth: status, assignee, sequencing, blockers, ownership. |
| Source code | Implementation. |

**Rule:** any "is this task done?" / "what's the active queue?" question MUST be answered by querying the tracker directly. Never grep `plans/phases.yaml` for status or for the dependency graph.

## Branch strategy

- `main` → integration (protected, PRs only)
- `feat/{TICKET-ID}-{slug}` → working branches in worktrees, PR'd into main

## Skill ↔ verb contract

Skills (`/pickup-task`, `/plan-task`, `/implement`, `/ship`, etc.) own user-facing UX: question prompts, confirmation gates, plan display. CLI verbs (`forge orchestrate <verb>` — `claim`, `dispatch`, `complete`, etc.) own the state machine: idempotent transitions, lease management, atomic file writes.

**Rule:** skills NEVER mutate orchestrator state directly. Every state change goes through a verb. This keeps the state machine testable in isolation and means interactive flows and automated flows share one code path.

## Ephemeral ADR workflow (v0.5+)

In-flight architectural decisions are drafted as ephemeral ADRs in `spec/decisions/<YYYY-MM-DD>-<kebab-slug>.md`. The `/update-spec --apply <slug>` skill propagates an accepted ADR to SPEC + PRD + `phases.yaml` + tracker bodies, then deletes the ADR file. SPEC remains the sole durable source of truth — no permanent ADR archive.

## Critical paths convention

Files matching patterns in your repo's `CRITICAL.md` trigger `/second-opinion` auto-review on `/ship`. The **list** is user-curated in `CRITICAL.md` at your repo root. The **convention** (what the list means, when it triggers) is Forge-defined and documented here.
```

```typescript
import type { RegistryEntry } from '../registry.ts';

export interface RenderContextInput {
  readonly version: string;
  readonly verbs: readonly RegistryEntry[];
  readonly slashCommands: readonly RegistryEntry[];
}

const NONE_MARKER = '_(none)_';

function renderEntries(entries: readonly RegistryEntry[], prefix: string): string {
  if (entries.length === 0) return NONE_MARKER;
  return entries.map((e) => `- \`${prefix}${e.name}\` — ${e.summary}`).join('\n');
}

export function renderContext(template: string, input: RenderContextInput): string {
  const verbsBlock = renderEntries(input.verbs, 'forge orchestrate ');
  const slashBlock = renderEntries(input.slashCommands, '/');

  const rendered = template
    .replaceAll('{{METHODOLOGY_VERSION}}', input.version)
    .replaceAll('{{CLI_VERBS_BLOCK}}', verbsBlock)
    .replaceAll('{{SLASH_COMMANDS_BLOCK}}', slashBlock);

  return rendered;
}
```

```typescript
function proseBody(input: PrefixBlockInput, agent: 'codex' | 'gemini'): string {
  return `> This project uses [Forge](${input.repoUrl}). Before any work, read \`.forge/CONTEXT.md\`
> for the methodology this project follows. If that file is missing, install Forge with:

}

export function buildPrefixBlock(agent: AgentKind, input: PrefixBlockInput): string {
  const body =
    agent === 'claude_code' ? claudeBody(input) : proseBody(input, agent);
  return `${MARKER_OPEN}\n${body}\n${MARKER_CLOSE}\n`;
}

const blockRegex = new RegExp(
  `${escapeRegex(MARKER_OPEN)}[\\s\\S]*?${escapeRegex(MARKER_CLOSE)}\\n?`,
  'm',
);

function escapeRegex(s: string): string {
  return s.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
}

export function replacePrefixBlock(fileContents: string, newBlock: string): string {
  if (blockRegex.test(fileContents)) {
    return fileContents.replace(blockRegex, newBlock);
  }
  // No existing block — prepend with a separating blank line if the file is non-empty.
  if (fileContents.length === 0) return newBlock;
  return `${newBlock}\n${fileContents}`;
}

export function extractPrefixBlock(fileContents: string): string | null {
  const match = fileContents.match(blockRegex);
  return match ? match[0] : null;
}

export function bodyWithoutPrefixBlock(fileContents: string): string {
  return fileContents.replace(blockRegex, '').replace(/^\n+/, '');
}
```

```typescript
const MARKER_OPEN = '# >>> forge-managed (do not edit between markers) >>>';
const MARKER_CLOSE = '# <<< forge-managed <<<';

const BLOCK_BODY = [
  '/.forge/*',
  '!/.forge/settings.yaml',
].join('\n');

const FULL_BLOCK = `${MARKER_OPEN}\n${BLOCK_BODY}\n${MARKER_CLOSE}\n`;

function escapeRegex(s: string): string {
  return s.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
}

const blockRegex = new RegExp(
  `${escapeRegex(MARKER_OPEN)}[\\s\\S]*?${escapeRegex(MARKER_CLOSE)}\\n?`,
  'm',
);

export function applyGitignoreBlock(contents: string): string {
  if (blockRegex.test(contents)) {
    return contents.replace(blockRegex, FULL_BLOCK);
  }
  if (contents.length === 0) return FULL_BLOCK;
  const sep = contents.endsWith('\n') ? '\n' : '\n\n';
  return `${contents}${sep}${FULL_BLOCK}`;
}

export function hasGitignoreBlock(contents: string): boolean {
  return blockRegex.test(contents);
}
```

```typescript
import { createHash } from 'node:crypto';
import { existsSync, readFileSync, writeFileSync } from 'node:fs';
import { resolve } from 'node:path';
import { parse as yamlParse } from 'yaml';
import { renderContext } from './render-context.ts';
import { buildPrefixBlock, ROOT_FILE_BY_AGENT, replacePrefixBlock, type AgentKind } from './agent-root-files.ts';
import { applyGitignoreBlock } from './gitignore-block.ts';
import { CLI_VERBS, SLASH_COMMANDS } from '../registry.ts';

export interface UpgradeOptions {
  readonly cwd: string;
  readonly force?: boolean;
  readonly dryRun?: boolean;
}

export interface UpgradeResult {
  readonly exitCode: number;
  readonly filesChanged: readonly string[];
  readonly stderr: string;
}

function sha256(s: string): string {
  return createHash('sha256').update(s).digest('hex');
}

function readPackageVersion(): string {
  const pkgPath = resolve(import.meta.dirname, '../../../package.json');
  return (JSON.parse(readFileSync(pkgPath, 'utf8')) as { version: string }).version;
}

function loadBundledTemplate(): string {
  // Resolve `templates/CONTEXT.template.md` relative to bundled location.
  // In dev, that's repo root; in installed package, dist-relative.
  return readFileSync(
    resolve(import.meta.dirname, '../../../templates/CONTEXT.template.md'),
    'utf8',
  );
}

export async function upgrade(opts: UpgradeOptions): Promise<UpgradeResult> {
  const stderr: string[] = [];
  const changed: string[] = [];

  // 1. Read settings.
  const settingsPath = resolve(opts.cwd, '.forge/settings.yaml');
  if (!existsSync(settingsPath)) {
    stderr.push('forge upgrade: .forge/settings.yaml not found. Run `forge init` first.');
    return { exitCode: 3, filesChanged: [], stderr: stderr.join('\n') };
  }
  const settings = yamlParse(readFileSync(settingsPath, 'utf8')) as {
    agents: { enabled_root_files: AgentKind[] };
  };

  // 2. Compute bundled CONTEXT.md.
  const version = readPackageVersion();
  const template = loadBundledTemplate();
  const desiredContext = renderContext(template, {
    version,
    verbs: CLI_VERBS,
    slashCommands: SLASH_COMMANDS,
  });

  // 3. Compare to on-disk CONTEXT.md.
  const contextPath = resolve(opts.cwd, '.forge/CONTEXT.md');
  const onDiskContext = existsSync(contextPath) ? readFileSync(contextPath, 'utf8') : '';

  if (sha256(onDiskContext) !== sha256(desiredContext)) {
    if (!opts.force && onDiskContext.length > 0) {
      stderr.push(
        'forge upgrade: .forge/CONTEXT.md has local edits or is stale.',
        'Re-run with --force to overwrite (your edits will be saved as .forge/CONTEXT.md.bak).',
      );
      return { exitCode: 1, filesChanged: [], stderr: stderr.join('\n') };
    }
    if (!opts.dryRun) {
      if (onDiskContext.length > 0 && opts.force) {
        writeFileSync(`${contextPath}.bak`, onDiskContext);
      }
      writeFileSync(contextPath, desiredContext);
    }
    changed.push('.forge/CONTEXT.md');
  }

  // 4. Refresh .forge/.version.
  const versionPath = resolve(opts.cwd, '.forge/.version');
  const onDiskVersion = existsSync(versionPath) ? readFileSync(versionPath, 'utf8').trim() : '';
  if (onDiskVersion !== version) {
    if (!opts.dryRun) writeFileSync(versionPath, `${version}\n`);
    changed.push('.forge/.version');
  }

  // 5. Refresh each enabled agent's root file prefix block.
  for (const agent of settings.agents.enabled_root_files) {
    const fileName = ROOT_FILE_BY_AGENT[agent];
    const filePath = resolve(opts.cwd, fileName);
    if (!existsSync(filePath)) continue; // First-time --add-agent handled in B4.
    const fileContents = readFileSync(filePath, 'utf8');
    const desiredPrefix = buildPrefixBlock(agent, { repoUrl: 'https://github.com/firatcand/forge' });
    const updated = replacePrefixBlock(fileContents, desiredPrefix);
    if (updated !== fileContents) {
      if (!opts.dryRun) writeFileSync(filePath, updated);
      changed.push(fileName);
    }
  }

  // 6. Refresh .gitignore marker block.
  const gitignorePath = resolve(opts.cwd, '.gitignore');
  const currentGitignore = existsSync(gitignorePath) ? readFileSync(gitignorePath, 'utf8') : '';
  const desiredGitignore = applyGitignoreBlock(currentGitignore);
  if (desiredGitignore !== currentGitignore) {
    if (!opts.dryRun) writeFileSync(gitignorePath, desiredGitignore);
    changed.push('.gitignore');
  }

  return { exitCode: 0, filesChanged: changed, stderr: stderr.join('\n') };
}
```

```typescript
import { existsSync, readFileSync } from 'node:fs';
import { resolve } from 'node:path';

export interface DriftInfo {
  readonly onDisk: string;
  readonly current: string;
}

export interface CheckVersionDriftInput {
  readonly cwd: string;
  readonly currentVersion: string;
}

export function checkVersionDrift(input: CheckVersionDriftInput): DriftInfo | null {
  const path = resolve(input.cwd, '.forge/.version');
  if (!existsSync(path)) return null;
  const onDisk = readFileSync(path, 'utf8').trim();
  if (onDisk === input.currentVersion) return null;
  return { onDisk, current: input.currentVersion };
}

export function formatDriftWarning(drift: DriftInfo): string {
  return `forge: this repo's methodology is v${drift.onDisk}; your CLI bundles v${drift.current}. Run \`forge upgrade\` to refresh.`;
}
```

```typescript
import { createHash } from 'node:crypto';
import { existsSync, readFileSync, writeFileSync } from 'node:fs';
import { resolve } from 'node:path';
import { buildPrefixBlock } from './agent-root-files.ts';
import { renderContext } from './render-context.ts';
import { CLI_VERBS, SLASH_COMMANDS } from '../registry.ts';

interface MigrateOptions {
  readonly cwd: string;
}

interface MigrateResult {
  readonly exitCode: number;
  readonly stderr: string;
}

// Section headings (exact match) we expect in the legacy file:
const METHODOLOGY_HEADINGS = [
  '## Forge principles',
  '## Source of truth',
  '## Skill ↔ verb contract',
  '## Ephemeral ADR workflow',
  '## Critical paths',
  '## Branch strategy',
] as const;

const MANUAL_RECIPE = `
Manual migration:
  1. Save your current CLAUDE.md as CLAUDE.md.pre-migration.bak
  2. Remove these sections from CLAUDE.md: ${METHODOLOGY_HEADINGS.join(', ')}
  3. Add the Forge prefix block at top of CLAUDE.md (see spec/decisions/2026-05-21-claudemd-methodology-split.md §5)
  4. Run \`forge upgrade\` to materialize .forge/CONTEXT.md
`.trim();

function sectionBody(content: string, heading: string): string | null {
  const idx = content.indexOf(`\n${heading}\n`);
  if (idx === -1 && !content.startsWith(`${heading}\n`)) return null;
  const start = idx === -1 ? heading.length + 1 : idx + 1;
  // Find next "## " heading or EOF
  const afterStart = start + heading.length;
  const next = content.slice(afterStart).search(/\n## /);
  const end = next === -1 ? content.length : afterStart + next;
  return content.slice(start, end);
}

function sha256(s: string): string {
  return createHash('sha256').update(s).digest('hex');
}

// Reference SHAs of each methodology section from the v0.4 bundled template.
// Generated by running: for each heading, extract from test/fixtures/legacy-claudemd.md, sha256.
const REFERENCE_SHAS: Readonly<Record<string, string>> = {
  // populate at test-fixture-creation time
  // '## Forge principles': '…',
  // …
};

export async function migrateClaudemd(opts: MigrateOptions): Promise<MigrateResult> {
  const claudePath = resolve(opts.cwd, 'CLAUDE.md');
  const contextPath = resolve(opts.cwd, '.forge/CONTEXT.md');

  if (existsSync(contextPath)) {
    return {
      exitCode: 1,
      stderr: 'forge upgrade --migrate-claudemd: .forge/CONTEXT.md already exists. Migration is one-shot; this repo appears to already be migrated.',
    };
  }
  if (!existsSync(claudePath)) {
    return {
      exitCode: 1,
      stderr: 'forge upgrade --migrate-claudemd: no CLAUDE.md found in cwd.',
    };
  }

  const original = readFileSync(claudePath, 'utf8');

  // Strict-match each methodology section.
  for (const heading of METHODOLOGY_HEADINGS) {
    const body = sectionBody(original, heading);
    if (body === null) {
      return {
        exitCode: 0,
        stderr: `forge upgrade --migrate-claudemd: heading "${heading}" not found. Bailing cleanly.\n${MANUAL_RECIPE}`,
      };
    }
    if (REFERENCE_SHAS[heading] && sha256(body) !== REFERENCE_SHAS[heading]) {
      return {
        exitCode: 0,
        stderr: `forge upgrade --migrate-claudemd: section "${heading}" has drifted from the v0.4 reference. Bailing cleanly.\n${MANUAL_RECIPE}`,
      };
    }
  }

  // Build new CLAUDE.md: remove the methodology sections, prepend prefix block.
  let trimmed = original;
  for (const heading of METHODOLOGY_HEADINGS) {
    const body = sectionBody(trimmed, heading) ?? '';
    trimmed = trimmed.replace(`${heading}\n${body}`, '').replace(/\n{3,}/g, '\n\n');
  }
  const prefix = buildPrefixBlock('claude_code', { repoUrl: 'https://github.com/firatcand/forge' });
  const newClaude = `${prefix}\n${trimmed.trimStart()}`;

  // Write backup.
  writeFileSync(`${claudePath}.pre-migration.bak`, original);
  writeFileSync(claudePath, newClaude);

  // Materialize .forge/CONTEXT.md from bundled template.
  const template = readFileSync(
    resolve(import.meta.dirname, '../../../templates/CONTEXT.template.md'),
    'utf8',
  );
  const pkg = JSON.parse(
    readFileSync(resolve(import.meta.dirname, '../../../package.json'), 'utf8'),
  ) as { version: string };
  const rendered = renderContext(template, {
    version: pkg.version,
    verbs: CLI_VERBS,
    slashCommands: SLASH_COMMANDS,
  });
  writeFileSync(contextPath, rendered);

  return {
    exitCode: 0,
    stderr: `migrated CLAUDE.md (original saved to CLAUDE.md.pre-migration.bak). Run \`forge upgrade\` after pulling on each dev's machine to materialize their own .forge/CONTEXT.md.`,
  };
}
```
